# The Scriptorium

A collection of CSS components for AO3 workskins. Originally built for my own fanfiction, shared here in case it's useful to others.

## Components

- **Parchment background** — simple textured parchment background
- **Parchment scroll** — decorative parchment scroll with a fixed size and scrollable content area
- **Book** — dark ornate book cover with decorative border, with an optional decorative image variant
- **Newspaper** — sepia-toned newspaper layout, with an optional decorative image variant

Usage and HTML examples available on [AO3](https://archiveofourown.org/works/84721106).

## Assets

The `assets/` folder contains the textures used by the workskin. All images are free to use, with one exception: `book-border.png` was generated with Gemini (Google AI). If you prefer not to use AI-generated assets, you can swap it out: the CSS will work with any image with minor adjustments.

- `newspaper-image.jpg`: photo by [Jupilu](https://pixabay.com/users/jupilu/) via Pixabay
- `old-parchment.png`: parchment scroll designed by [Magnific](www.magnific.com)
