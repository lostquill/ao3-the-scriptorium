# The Scriptorium
A collection of CSS components for AO3 workskins: simple document-style formatting elements with an antiquarian feel.

## Components

### main.css
- **Parchment background** — simple textured parchment background
- **Parchment scroll** — decorative parchment scroll with a fixed size and scrollable content area
- **Folio** — aged parchment document with a wax seal
- **Codex** — illuminated manuscript page on aged parchment, with a decorative double border and an optional drop cap
- **Book** — dark ornate book cover with a decorative border; supports nesting a `.parchment` inner page
- **Newspaper** — sepia-toned newspaper layout
- **Diary/Notebook** — handwritten diary page on ruled notebook paper with a red margin line
- **File** — single classified file page styled like a typewritten dossier

### document-tabs.css
- Tabbed document viewer including six visual variants: `.doc-folio`, `.doc-codex`, `.doc-book`, `.doc-newspaper`, `.doc-diary`, and `.doc-folders`. They also feature an optional `.bigger` modifier for larger dimensions.

Usage and HTML examples available on [AO3](https://archiveofourown.org/works/84721106).
